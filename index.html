Mathematical Explanation

By calculating the derivative of the survivability multiplier function M(R) with respect to damage reduction R, we measure how steep the curve is at any given point:

M'(R) = d/dR [ 1 / (1 - R) ] = 1 / (1 - R)² = [ M(R) ]²
